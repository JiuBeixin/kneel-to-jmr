## ❓ 常见问题

**需要 GitHub 账号吗？**
一般不需要，一键直达，圣旨自动送达。若圣旨通道繁忙（token 失效），会改走 GitHub 预填页面，此时需要登录 GitHub 点一下 `Submit`。

**称臣后名册没刷新？**
点「🔄 刷新名册」；若仍无变化，按一次 `Ctrl+F5` 硬刷新即可。

**封号不满意怎么办？**
钦此，没有商量的余地。可以换个尊号再表一次（不建议，会被发现）。

**为什么我的名字能点？**
点开就是你那条圣旨 Issue，可截图发群炫耀。
